Message: feat: add components, service, and views for managing journal volumes and issues in admin dashboard
Activities & Detailed Breakdown:
  1. Component: NewJournalVolumeIssues (Create & Publish Journal Issues)
     - Location: src/app/views/pages/Journal-Editors-AdminDashboard/AddNewVolumeIssue/NewJournalVolumeIssues/
     - Form: Reactive FormGroup with controls (IssueDescription, PublishDate, IssueTitle, PageNumber).
     - Stepper Logic: UpdateVolume() & UpdateIssueNumber() with strict upper/lower bound checks (+1 max).
     - Author Management: Dynamic multi-author input with Enter/comma parsing, chip UI, and deduplication.
     - File Upload: 3MB limit, regex sanitization (/^[a-zA-Z0-9._-]+$/), and base64 conversion via FileReader.
     - API Integration: Submits multipart/form-data to AddNewIssuesDetails() with SweetAlert2 status handling.

  2. Component: ViewAllJournalIssues (List, Paginate & Reject Issues)
     - Location: src/app/views/pages/Journal-Editors-AdminDashboard/ViewAllJournalIssues/
     - Table Grid: Displays journal title, volume, publish date, issue number/title, author, and page number.
     - Pagination: Client-side 10 items/page pagination with Previous/Next controls.
     - Dual-Phase Loading: Separate indicators for page initialization and journal issue data loading.
     - Disapprove Workflow: DisapproveStatus() SweetAlert2 input prompt capturing rejection reason; calls DisableIssue().

  3. Component: UpdateIssueDetails (Interactive Issue Editing)
     - Location: src/app/views/pages/Journal-Editors-AdminDashboard/UpdateIssueDetails/
     - Modal: Integrated with Bootstrap 5 Modal (#UpdateIssueDetailsModal).
     - Form Pre-filling: Auto-populates fields, parses comma-separated authors, formats dates to 'YYYY-MM-DD'.
     - Optional File Replacement: Supports optional re-upload while preserving existing file if unedited.
     - API Integration: Submits updated payload to UpdateIssueDetails() and refreshes issue list on success.

  4. Service Layer (LpujournalbookService):
     - Location: src/app/_services/lpujournalbook.service.ts
     - AddNewIssuesDetails(FormData): POST api/LpuJournal/AddNewJournalIssueData
     - GetJournalIssues(JournalId): GET api/LpuJournal/GetJournalIssuesDetails
     - UpdateIssueDetails(FormData): POST api/LpuJournal/UpdateJournalIssueDetails
     - DisableIssue(FormData): POST api/LpuJournal/UpdateJournalIssueStatus

  5. Routing (app-routing.module.ts):
     - Route 'NewVolume' -> NewJournalVolumeIssuesModule
     - Route 'AllVolumesIssues' -> ViewAllJournalIssuesModule
     - Route 'EditIssueDetails' -> UpdateIssueDetailsModule
